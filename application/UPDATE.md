# StormStore v3.0.0

## Registro de cambios

### Nuevas funciones

- Añadido StormVortex como modo de juego independiente.
- Añadida una cola global de instalaciones para descargar e instalar un solo programa cada vez.
- Ahora se puede salir de `program-updates.html` y continuar añadiendo programas a la cola.
- La cola muestra todas las instalaciones pendientes y la descarga activa.
- El gestor de descargas cambia automáticamente al siguiente programa.
- Añadido el acceso al gestor de descargas en todos los sidebars.

### Mejoras visuales

- Tarjetas de aplicaciones renovadas con imágenes más destacadas.
- Añadidos bordes, fondos elevados y sombras sutiles.
- Etiquetas de estado para `Instalada`, `Actualizar` y `Nueva`.
- Mejoras en los estados de carga de los botones de instalación.

### Correcciones

- Evitadas las instalaciones duplicadas del mismo programa.
- Las carpetas temporales de descarga ahora se crean de forma independiente para evitar conflictos de permisos.
- Añadido un aviso específico cuando Windows bloquea temporalmente la carpeta del juego.
- El botón `Reintentar` permite continuar después de cerrar el juego o liberar la carpeta bloqueada.
- Actualizada la configuración del instalador para la versión 3.0.0.
